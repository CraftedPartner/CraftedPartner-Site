# CraftedPartner-Site

Static site for www.craftedconsultingusa.com, served by GitHub Pages from `main`.

- Shared styles: `assets/css/site.css`. Shared script: `assets/js/site.js`.
- Every page links them with a version tag (`site.css?v=...`). After changing
  either file, update the tag on every page so browsers don't mix a new page
  with a cached old stylesheet.
- `googlebe67c03cd54b7d2a.html` keeps Google Search Console verified. Leave it.
